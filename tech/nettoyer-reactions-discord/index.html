Retirer en masse les réactions des anciens membres d'un Discord

22 novembre 2026 · pas à pas, avec un petit bot jetable et un script en simulation d'abord

Le problème

Un message de rôles à réactions (ici celui d'un bot de rôles) affiche des compteurs qui incluent des gens partis du serveur. Discord n'a pas de bouton « retirer les réactions des anciens membres », et le faire un par un est impossible quand il y a plusieurs centaines de réactions. Il faut un bot qui parcourt les réactions et retire celles des comptes absents du serveur.

Le principe en un coup d'œil

Lecture : seule la réponse « introuvable » entraîne un retrait. Au moindre doute, rien n'est supprimé.

À ne pas faire : automatiser avec ton propre compte (script dans la console du navigateur, « selfbot »). C'est contraire aux conditions d'utilisation de Discord et ton compte admin risque le bannissement. Un vrai bot est la seule voie autorisée.

Ce qu'il te faut

  • Être administrateur (ou avoir « Gérer les messages ») sur le serveur.
  • Python 3 installé (python --version dans PowerShell).
  • 10 minutes. Le bot ne tourne que le temps du script, sur ton PC.

1. Créer le bot

  1. Ouvre discord.com/developers/applications avec ton compte Discord.
  2. Nouvelle application, donne un nom (par ex. « Nettoyage »), accepte les conditions, Créer. Crée-en une neuve plutôt que de réutiliser une application dont tu ne te souviens plus des droits.
  3. Menu de gauche, Bot, puis Réinitialiser le jeton, confirme et copie-le. Il ne s'affiche qu'une fois.
Le jeton est un mot de passe. Qui l'a contrôle ton bot. Ne le colle ni dans un message, ni dans un fichier, ni dans un dépôt Git, ni dans une capture d'écran. Si tu le divulgues, réinitialise-le aussitôt.

2. L'inviter sur le serveur avec le minimum de droits

  1. Menu OAuth2, section « Générateur d'URL OAuth2 ». Coche le champ bot (colonne du milieu).
  2. Dans « Permissions du bot », coche seulement trois cases :
Case (en français)Nom anglaisPourquoi
Voir les salonsView Channelstrouver le salon
Voir les anciens messagesRead Message Historylire le message de rôles
Gérer les messagesManage Messagesretirer une réaction
  1. Copie l'URL générée en bas, ouvre-la dans le navigateur, choisis ton serveur, Autoriser.
  2. Si le salon des rôles est restreint : clic droit sur le salon, Modifier le salon, Permissions, ajoute le bot (ou son rôle) et mets ✓ sur « Voir le salon », « Gérer les messages » et « Voir les anciens messages ».

3. Récupérer les identifiants

  1. Discord : Paramètres utilisateur, Avancé, active le Mode développeur.
  2. Clic droit sur le salon, Copier l'identifiant du salon.
  3. Clic droit sur chaque message de rôles, Copier l'identifiant du message.

Ces nombres ne sont pas secrets, mais je ne publie pas les miens : remplace les exemples du script par les tiens.

Plusieurs messages : comment les écrire

Dans le script, MESSAGE_IDS est une liste : des crochets autour, les identifiants séparés par des virgules, sans guillemets (ce sont des nombres).

ÉcritureVerdict
✅[111111111111111111, 222222222222222222, 333333333333333333]correct, 3 messages
✅[111111111111111111]correct, 1 seul message
❌["111…", "222…"]guillemets en trop
❌[111… 222…]virgule oubliée
❌111…, 222…crochets oubliés

Pour la lisibilité, tu peux aussi mettre un identifiant par ligne :

MESSAGE_IDS = [
    111111111111111111,
    222222222222222222,
    333333333333333333,
]

Règle importante : tous les messages d'une exécution doivent être dans le même salon, celui de CHANNEL_ID.

Un message d'un autre salon ne casse rien : le script l'écrit comme « ignoré » et continue avec les autres.

4. Le script

Enregistre ceci dans nettoie_reactions.py. Par défaut, il simule : il liste ce qu'il retirerait sans rien supprimer.

import os, sys, discord

CHANNEL_ID = 111111111111111111          # ton identifiant de salon
MESSAGE_IDS = [222222222222222222,       # un ou plusieurs identifiants de message,
               333333333333333333]       # séparés par des virgules, sans guillemets
SUPPRIMER = "--supprimer" in sys.argv    # sans cet argument : simulation

client = discord.Client(intents=discord.Intents.default())
presents = {}

async def est_present(guild, uid):
    if uid not in presents:
        try:
            await guild.fetch_member(uid)
            presents[uid] = True
        except discord.NotFound:          # seule réponse qui veut dire « parti »
            presents[uid] = False
    return presents[uid]

@client.event
async def on_ready():
    ch = await client.fetch_channel(CHANNEL_ID)
    guild = ch.guild
    total, vus, par_emoji = 0, 0, {}
    print("MODE : " + ("SUPPRESSION RÉELLE" if SUPPRIMER else "SIMULATION (rien n'est supprimé)"))
    for mid in MESSAGE_IDS:
        try:
            msg = await ch.fetch_message(mid)
        except discord.NotFound:
            print(f"Message {mid} introuvable dans ce salon, ignoré")
            continue
        print(f"--- message {mid} ---")
        for r in msg.reactions:
            async for u in r.users():
                if u.id == client.user.id:
                    continue
                vus += 1
                if not await est_present(guild, u.id):
                    total += 1
                    par_emoji[str(r.emoji)] = par_emoji.get(str(r.emoji), 0) + 1
                    if SUPPRIMER:
                        print(f"RETIRÉ        {r.emoji}  {u} ({u.id})")
                        await msg.remove_reaction(r.emoji, u)
                    else:
                        print(f"[SIMULATION] retirerait  {r.emoji}  {u} ({u.id})")
    print("\n=== Récapitulatif ===")
    print(f"Réactions examinées : {vus}")
    for e, n in par_emoji.items():
        print(f"  {e} : {n} à retirer")
    print(f"Total {'retiré' if SUPPRIMER else 'à retirer (simulation, RIEN supprimé)'} : {total}")
    await client.close()

client.run(os.environ["DISCORD_TOKEN"])

5. Lancer : d'abord la simulation

Dans PowerShell, dans le dossier du script, une commande à la fois :

pip install discord.py
$env:DISCORD_TOKEN = "colle_ton_jeton_ici"
python nettoie_reactions.py

Le jeton est une variable de cette fenêtre PowerShell seulement : il disparaît quand tu la fermes.

  1. Lis la ligne MODE : SIMULATION en haut, puis la liste et le récapitulatif par emoji.
  2. Contrôle au hasard : prends deux ou trois pseudos de la liste et cherche-les dans la liste des membres du serveur. Ils ne doivent pas y être.
  3. Si tout est juste, relance avec la suppression réelle :
python nettoie_reactions.py --supprimer

Compte quelques minutes pour plusieurs centaines de réactions : la bibliothèque respecte seule les limites de débit de Discord. Les compteurs sous le message baissent en direct.

Ce que le script touche, et ce qu'il ne touche pas

TouchéJamais touché
Les réactions, sur les messages listés, de comptes qui ne sont plus membres du serveurLes réactions des membres présents, les autres messages et salons, les rôles, les réactions posées par le bot lui-même

Une erreur de Discord (droits manquants, coupure) arrête le script au lieu de retirer par défaut : seule la réponse « introuvable » classe un compte comme parti. Un compte supprimé définitivement compte aussi comme parti, ce qui est voulu. Retirer une réaction est définitif, d'où la simulation d'abord.

6. Après : ranger

  • One-shot : supprime l'application sur le portail développeur. Un jeton qui traîne finit par fuiter.
  • Réutilisable : garde-la, avec le jeton dans un gestionnaire de mots de passe. Le bot ne fait que ce que ses droits permettent : pour d'autres tâches (supprimer des messages en masse, exporter un salon), il suffit d'un autre script. Pour des droits en plus, génère une nouvelle URL d'invitation.
  • Un script lancé à la main ne tourne que pendant son exécution. Un bot qui répond en continu à des commandes demande un programme différent, sur une machine toujours allumée.
